JARVIS Browser Agent 3.1.0

Install in Chrome, Edge, or Brave:
1. Extract this ZIP file.
2. Open the browser's Extensions page and enable Developer mode.
3. Choose "Load unpacked" and select the extracted folder.
4. Click the JARVIS toolbar button, set your JARVIS API URL, and save it. If your server requires `JARVIS_ACCESS_TOKEN`, enter that shared access token in the password field (never put a provider API key in the extension).
5. Open a regular website, allow microphone access if you want voice input, then click the orb or press Alt+J.

The extension uses the configured JARVIS API for AI tasks. Direct browser commands run locally. Fast brain mode skips its extra planning call. Point at a link or button and say "click that", "open that", or "open that in a new tab". Escape or Stop cancels a running request.
