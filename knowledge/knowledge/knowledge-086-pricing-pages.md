# Pricing Pages

Pricing should show plan name, cost, usage limits, feature unlocks, and billing period.

## ARIA use

- Match this file when the user asks about plans, features.
- Prefer account memory first, then this library, then Google knowledge if configured.
- Give practical steps and ask permission before sensitive actions.
