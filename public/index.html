Documentation
Get started in 2 minutes
Three steps to your first AI response.
Step 1 — Get your key

Your key is on the API Keys page. It starts with sk-aria-

Step 2 — cURL
curl
curl https://aria-sigma-gold.vercel.app/v1/chat \ -H "Authorization: Bearer sk-aria-YOUR_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "aria-smart", "messages": [{"role": "user", "content": "Hello ARIA!"}] }'
Step 3 — Python
python
import requests API_KEY = "sk-aria-YOUR_KEY" res = requests.post( "https://aria-sigma-gold.vercel.app/v1/chat", headers={ "Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json" }, json={ "model": "aria-smart", "messages": [{ "role": "user", "content": "Explain quantum computing" }] } ) data = res.json() print(data["content"][0]["text"])
Step 3 — JavaScript
javascript
const res = await fetch('https://aria-sigma-gold.vercel.app/v1/chat', { method: 'POST', headers: { 'Authorization': 'Bearer sk-aria-YOUR_KEY', 'Content-Type': 'application/json' }, body: JSON.stringify({ model: 'aria-smart', messages: [{ role: 'user', content: 'Hello!' }] }) }); const data = await res.json(); console.log(data.content[0].text);

Base URL
BASEhttps://aria-sigma-gold.vercel.app
POST /v1/chat
POST/v1/chat

Send messages and receive a completion from ARIA.

Request

json
{ "model": "aria-smart", // aria-fast | aria-smart | aria-pro "messages": [{ // required "role": "user", "content": "Your message" }], "system": "You are helpful", // optional "max_tokens": 1024, // optional, default 1024 "stream": false // optional, SSE streaming }

Response

json
{ "id": "msg_01XFDUDYJgAACzvnptvVoYEL", "type": "message", "role": "assistant", "content": [{ "type": "text", "text": "Hello!" }], "model": "aria-smart", "usage": { "credits_used": 4 } }
