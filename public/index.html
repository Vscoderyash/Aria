Quickstart
Start calling ARIA API in under 2 minutes
1. Get your API key

Your key is on the API Keys page. It starts with sk-aria-

2. Make your first call
curl
curl https://aria-sigma-gold.vercel.app/v1/chat \
  -H "Authorization: Bearer sk-aria-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aria-smart",
    "messages": [
      {"role": "user", "content": "Hello ARIA!"}
    ]
  }'
3. Python
python
import requests

API_KEY = "sk-aria-YOUR_KEY"
BASE_URL = "https://aria-sigma-gold.vercel.app"

response = requests.post(
    f"{BASE_URL}/v1/chat",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    },
    json={
        "model": "aria-smart",
        "messages": [{
            "role": "user",
            "content": "Explain quantum computing"
        }]
    }
)

data = response.json()
print(data["content"][0]["text"])
4. JavaScript / Node.js
javascript
const res = await fetch('https://aria-sigma-gold.vercel.app/v1/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk-aria-YOUR_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'aria-smart',
    messages: [{ role: 'user', content: 'Hello!' }]
  })
});

const data = await res.json();
console.log(data.content[0].text);

API Reference

Base URL
BASEhttps://aria-sigma-gold.vercel.app
POST /v1/chat
POST/v1/chat

Send a message and get a response from ARIA.

Request body

json
{
  "model":      "aria-smart",        // aria-fast | aria-smart | aria-pro
  "messages":   [{                     // required
    "role":    "user",
    "content": "Your message here"
  }],
  "system":     "You are helpful",   // optional system prompt
  "max_tokens": 1024,                 // optional, default 1024
  "stream":     false                 // optional, set true for SSE streaming
}

Response

json
{
  "id":      "msg_01XFDUDYJgAACzvnptvVoYEL",
  "type":    "message",
  "role":    "assistant",
  "content": [{
    "type": "text",
    "text": "Hello! How can I help you today?"
  }],
  "model":  "aria-smart",
  "usage":  { "credits_used": 4 }
}
