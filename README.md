# JARVIS

A clean chat site (`index.html`) plus one streaming Vercel function (`api/chat.js`) that uses the NVIDIA API.

1. Push this folder to GitHub and import it in Vercel (Framework: Other).
2. Set `NVIDIA_API_KEY` in Vercel > Settings > Environment Variables, then redeploy.
3. The sidebar links to the browser extension (`jarvis-extension.zip`) and the desktop app (`JARVIS-Desktop.zip`).
