ARIA needs a free Groq API key to run the AI model on the server.

1. Get a free key at console.groq.com
2. Go to your Vercel project → Settings → Environment Variables
3. Add: GROQ_API_KEY = your key
4. Redeploy — ARIA will be fully live.
